# Karteros Studios

A lightweight, cutting-edge portfolio site for Karteros Studios.

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Files
- `index.html` — site structure and portfolio content
- `styles.css` — responsive visual system, layouts and animation
- `script.js` — filtering, reveal motion, project dialogs and pointer effect

No build step or framework is required. The site is ready for a static host such as GitHub Pages, Netlify, Vercel or Cloudflare Pages.
